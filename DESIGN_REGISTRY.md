# Design System Registry • Fishtail Outer

## Visual Concept: Utilitarian Luxury & Military Mil-Spec Outerwear
A technical heritage aesthetic inspired by Korean War M-51 fishtail parkas, British Ventile all-weather dense cotton, and solid brass military hardware.

### Color Palette Tokens
- **Tactical Coyote / Khaki**: `#c29b62` (Primary accents, borders, and drawcord aglets)
- **Coyote Hover**: `#aa844d` (Interactive hover states)
- **Deep Olive Drab**: `#2d372e` (Secondary military green accents)
- **Weathered Gunmetal**: `#0f1214` (Darkest base panels & footers)
- **Technical Canvas Slate**: `#14171a` (Primary dark background canvas)
- **Outerwear Surface**: `#1b2024` (Card container surfaces)
- **Surface Alt Tint**: `#22282e` (Secondary tinted background sections)
- **Technical Border**: `#2c353d` (Military spec divider lines)
- **Ventile Off-White**: `#f0f3f6` (Primary typography and stark readouts)
- **Muted Canvas**: `#9ba8b5` (Subtitles, body copy, and technical specifications)
- **Safety Orange**: `#e05a2b` (Emergency flight lining accent)

### Typography Hierarchy
- **Display & Headings**: `Syne` (Google Fonts via `<link>`), font weights 700, 800.
- **Body & Technical UI**: `Space Grotesk` (Google Fonts via `<link>`), font weights 400, 500, 600, 700.

### Structural Framework
- Max Container Width: `1240px`
- Responsive Breakpoints: `1024px` (Tablet / Laptop), `768px` (Mobile Drawer)
- Card Shadow Tokens: `0 4px 15px rgba(0,0,0,0.35)` to `0 20px 50px rgba(0,0,0,0.75)`
